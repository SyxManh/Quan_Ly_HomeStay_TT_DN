# Quản lý Homestay khu vực trung tâm Đà Nẵng

Đồ án quản lý thông tin homestay, phòng nghỉ và đặt phòng tại khu vực trung tâm thành phố Đà Nẵng.

## Công nghệ dự kiến

- Python (Flask)
- MySQL
- Railway (triển khai bản xem trước)

## Trạng thái

Repository hiện có trang giới thiệu ban đầu để triển khai thử trên Railway. Các chức năng quản lý và kết nối cơ sở dữ liệu sẽ được nhóm phát triển tiếp.

## Chạy thử trên máy

```bash
pip install -r requirements.txt
python main.py
```

Sau đó mở http://localhost:5000.
